# Synthesis Netlists

This directory contains the post-synthesis structural netlists generated by the Xilinx Vivado Design Suite (v2023.2).

## Target Architecture
All designs were synthesized targeting the **Xilinx Versal VCK5000** Adaptive Compute Acceleration Platform (ACAP), which utilizes a 7nm FinFET process. 

## Synthesis Effects Observed
The netlists herein mathematically represent the EDA optimization effects discussed in the paper:
* Logic Thinning & Gate Collapsing were applied aggressively by the synthesis tool on dormant logic, reducing overall dynamic capacitance and causing the negative power signatures (-0.58% to -0.72%) observed in T1, T3, and T4.
